# Instructor requirements and submission checklist
**Guide:** OOP10 21-page Media Player Application Project, pp.2–7, Appendices A–E.

## M1 — Analysis/design (Nov 10)
- [ ] Requirements list with functional and non-functional priorities (FR1–FR13)
- [ ] Problem statement, users, scope/exclusions, use-case descriptions
- [ ] Use-case diagram + class diagram with interface/inheritance + sequence diagram
- [ ] Skin concept sketch, role matrix, group identity and FR8 declaration
- [x] Private repo established
- [ ] Instructor and members invited as collaborators when ready

## M2 — Core logic (Nov 10)
- [ ] Instructor starter imported and baseline built
- [ ] IMediaControls; abstract MediaItem, AudioItem, VideoItem; List<MediaItem>
- [ ] File I/O six-field Library.txt with corrupted-line/missing-file handling
- [ ] Save and auto-load working; first genuine tests

## M3 — Complete player/skin (Nov 10)
- [ ] Derived form with >=2 meaningful overrides + 1 new member
- [ ] MP3 + MP4 add, duration/title/artist/album or resolution, file type/path
- [ ] Play/Pause/Stop/Next/Previous and volume/seek
- [ ] Playlist, Now Playing, errors for empty/unsupported/missing/corrupt
- [ ] Original PNG skin, Theme.cs/ApplyTheme, no video obstruction
- [ ] Splash with logo, group, section, five photos/names/roles, timed/skip/placeholder
- [ ] Visible File/Playback/Library/Help menus, shortcuts
- [ ] Elapsed / total updated at least 1/sec
- [ ] Hand-written insertion sort by Title AND Artist, retain current item; trace and complexity explained
- [ ] Shuffle on/off and Repeat Off/All/One, end-of-item autoplay
- [ ] Favorites enhancement (separate persistence)

## M4 — Quality/docs/deployment (Nov 12)
- [ ] >=15 **executed** tests including negatives, results, bug log and retests
- [ ] User manual with annotated screenshots, troubleshooting and shortcuts
- [ ] Deployment guide, system requirements, known limitations
- [ ] Release x64 ZIP with VLC native plug-ins/Assets, tested on another Windows PC
- [ ] Refactoring and incremental development log, actual review/commit evidence

## M5 — Final (Nov 14)
- [ ] One PDF portfolio: cover + roster/photos/roles/contact; requirements; UML; milestone log; collaboration history; tests/bugs; manual; deployment; slides + individual reflections; source/design/credits appendix
- [ ] Repository link, PDF portfolio and Release ZIP named G1_BSCS2A_Item
- [ ] Recorded 10-minute demo (1m rationale, 2m UML, 4m live demo, 2m testing/lessons, 1m version control)
- [ ] All 5 members able to explain their and teammates' code
- [ ] Instructor collaborator added, genuine >=10 meaningful commits **per member**
- [ ] Royalty-free/self-made demo media and original/credited design assets

Never mark checkboxes complete until verified with real evidence.
